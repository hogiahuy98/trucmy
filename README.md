# Score GH × TM 💗

A cute and funny web app for tracking relationship points between GH and TM!

## Features

- 💗 Large pink button to increase score
- 📊 Level system with 5 different levels
- 📝 Activity log to track all the nice things done
- 🏆 Achievement system for milestones
- 💫 Flying heart animations
- 🔊 Sound effects when score increases
- 📤 Share button to share your progress
- 💾 Data persistence using localStorage
- 🎨 Beautiful, romantic UI with soft pink tones

## Getting Started

1. Install dependencies:
```bash
yarn install
```

2. Start the development server:
```bash
yarn dev
```

3. Open your browser and navigate to `http://localhost:3000`

## Build for Production

```bash
yarn build
```

Then start the production server with:

```bash
yarn start
```
